# 👕 Fashion-MNIST Image Classification Using CNN

A Deep Learning project that uses a **Convolutional Neural Network (CNN)** to classify clothing and footwear images from the Fashion-MNIST dataset into 10 different categories.

## 📌 Project Overview

Fashion-MNIST is a dataset of grayscale images representing different types of clothing and footwear. In this project, a CNN model is developed using TensorFlow and Keras to learn image features and predict the correct category.

The notebook covers data preprocessing, image visualization, CNN model development, model training, performance evaluation, and sample predictions.

## 🎯 Objectives

- Understand and explore the Fashion-MNIST dataset.
- Preprocess and normalize image data.
- Build a CNN model for image classification.
- Train the model using TensorFlow and Keras.
- Evaluate model performance on unseen test images.
- Visualize training curves and a confusion matrix.
- Compare actual labels with predicted labels.

## 🧹 Data Preprocessing

The following preprocessing techniques are applied:

- Reshaping images into `(28, 28, 1)` format.
- Normalizing pixel values from 0–255 to 0–1.
- Converting class labels into one-hot encoded vectors.
- Setting random seeds for reproducibility.
- Visualizing 25 sample images with their class labels.

## 🧠 CNN Model Architecture

The CNN model contains the following layers:

| Layer | Purpose |
|---|---|
| Input | Accepts 28 × 28 grayscale images |
| Conv2D (32 filters) | Extracts basic image features |
| MaxPooling2D | Reduces feature-map dimensions |
| Dropout (25%) | Helps reduce overfitting |
| Conv2D (64 filters) | Learns more complex features |
| MaxPooling2D | Further reduces dimensions |
| Dropout (25%) | Helps regularize the model |
| Flatten | Converts feature maps into a vector |
| Dense (128 neurons) | Learns classification patterns |
| Dropout (50%) | Helps reduce overfitting |
| Dense (10 neurons) | Predicts probabilities for 10 classes |

**Compilation settings:**
- Optimizer: Adam
- Loss Function: Categorical Cross-Entropy
- Evaluation Metric: Accuracy
- Maximum Epochs: 100
- Batch Size: 64
- Validation Split: 20%
- Early Stopping: Patience of 5 epochs

The best model checkpoint is saved as `best_fashion_mnist.keras`.

## 📈 Model Evaluation

The trained model is evaluated using the test dataset and multiple visualization techniques.

- **Test Accuracy:** Measures the proportion of correctly classified test images.
- **Test Loss:** Measures prediction error.
- **Training and Validation Curves:** Compare accuracy and loss across epochs.
- **Confusion Matrix:** Shows correct and incorrect classifications for each class.
- **Classification Report:** Provides precision, recall, F1-score, and support.
- **Sample Predictions:** Displays 25 test images with predicted and actual labels.
